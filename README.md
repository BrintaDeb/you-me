# YOU & ME — Cinematic Wedding Photography

> **Documentary wedding photography and cinematography shaped by warmth, emotion, and artistry.**

A high-end digital flagship and interactive portfolio for **YOU & ME**, designed with dark editorial aesthetics, ambient soundscapes, curated couple galleries, and immersive 35mm filmstrip archives.

---

## ✨ Features & Highlights

- **Cinematic Ambient Atmosphere**: Soothing audio texture streamed on page load at an ambient 8% volume ceiling with smart audio ducking when wedding films are viewed.
- **Interactive Heart Cursor**: Precision vector heart cursor with calm breathing dynamics and reactive click waves.
- **Hero Exhibition**: 5-second Ken-Burns cross-fading hero showcase highlighting real couples and ceremony destinations.
- **Complete Couple Archive**: 23 authentic couples cataloging 615+ high-resolution photographs with category filtering (*Traditional*, *Destination*, *Candid & Documentary*, *Bengali*).
- **Dual Portfolio Modes**: Toggle seamlessly between standard editorial Grid View and the **35mm Panoramic Filmstrip Reel** with Kodak Vision3 leader markings and continuous sprocket perforations.
- **Wedding Films in Motion**: 5 signature wedding film reels with high-definition posters and distraction-free playback modals.
- **Studio Availability Calendar**: Interactive seasonal calendar modal with real-time slot statuses and instant date booking inquiries.
- **Commercial Enquiry System**: Accessible contact form with local persistence, input validation, and direct studio WhatsApp and phone integration.
- **Full Responsive Optimization**: Rigorously verified across mobile (320px – 480px), tablet (768px – 1024px), and desktop viewports with 0 horizontal overflow and iOS Safari auto-zoom prevention.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Vanilla CSS Design System (Custom variables, glassmorphism, cinematic typography)
- **Animation**: GSAP + CSS Transitions & Keyframes
- **Icons**: Lucide React
- **Audio**: YouTube IFrame API (Audio-Only Stream)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/BrintaDeb/you-me.git
cd you-me

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will launch on `http://localhost:5173/`.

### Production Build

```bash
# Type check and bundle for production
npm run build

# Preview production build locally
npm run preview
```
